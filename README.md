# Minecraft-Plugins
Halihó! Yuzuma lennék, egy kezdő programozó. Leginkább Discord botok, weboldalak, és Minecraft fejlesztésével dolgozom. 
### Itt egy pár álltalam ismert nyelv:
- Java
- JavaScript
- Python
- PHP
- SQL
- HTMl
- CSS
Ha esetleg fejlesztőt keresnél, Minecraft szerverhez, vagy bármely más platformra, állok szívesen rendelkezésedre!
